## Add your real professional photo
Put your own portrait at:
`assets/profile.jpg`

The page will automatically use it. If it is absent, the site safely shows `assets/profile-placeholder.svg`.

Recommended: a clean portrait-oriented JPG/WebP with good lighting. The placeholder is intentionally not a generated likeness.
